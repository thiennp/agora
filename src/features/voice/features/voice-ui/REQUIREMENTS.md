# Voice UI — business requirements

Folder: `src/features/voice/features/voice-ui/`  ·  Top level: [REQUIREMENTS.md](../../../../../REQUIREMENTS.md)
Parent: [Voice](../../REQUIREMENTS.md)

## Purpose

The microphone experience.

## Who it serves

Parent owner.

## Requirements

| ID | Requirement | Priority | Acceptance |
|---|---|---|---|
| VOI-UI-01 | One large record button, usable one-handed. | Must | Reachable on a phone. |
| VOI-UI-02 | Show state clearly: listening, processing, done. | Must | State is always visible. |
| VOI-UI-03 | Work on a phone-width screen. | Must | No horizontal scrolling at 375 px. |

## Out of scope

- Hands-free continuous listening.

## Traceability

BR-17.
