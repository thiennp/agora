# Recalls — business requirements

Folder: `src/features/safety/features/recalls/`  ·  Top level: [REQUIREMENTS.md](../../../../../REQUIREMENTS.md)
Parent: [Safety](../../REQUIREMENTS.md)

## Purpose

Point owners to official recall information.

## Who it serves

Safety; owners.

## Requirements

| ID | Requirement | Priority | Acceptance |
|---|---|---|---|
| SAF-RCL-01 | Provide an official recall-check link per category and region. | Must | Links exist for each restricted category. |
| SAF-RCL-02 | Do not claim an item has been verified. | Must | Wording says "check", not "safe". |
| SAF-RCL-03 | Keep the link list easy to update. | Should | Links live in one file. |

## Out of scope

- Live recall database integration.

## Traceability

BR-10.
