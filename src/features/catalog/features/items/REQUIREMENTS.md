# Items — business requirements

Folder: `src/features/catalog/features/items/`  ·  Top level: [REQUIREMENTS.md](../../../../../REQUIREMENTS.md)
Parent: [Catalog](../../REQUIREMENTS.md)

## Purpose

Create, edit and withdraw individual offers and wants.

## Who it serves

Parent owner.

## Requirements

| ID | Requirement | Priority | Acceptance |
|---|---|---|---|
| CAT-ITM-01 | Create an offer or want from an intake draft or by hand. | Must | Both paths produce the same item shape. |
| CAT-ITM-02 | Withdraw or edit an item at any time before confirmation. | Must | Withdrawn items leave matching immediately. |
| CAT-ITM-03 | Attach safety flags to an item when a category rule applies. | Must | Flags are visible to both parties. |

## Out of scope

- Bulk import; auctions.

## Traceability

BR-03, BR-10.
