# ADR 0002 — Platform core separate from apps

Status: accepted (Oct 27, 2026)

## Context
Agora is a playground: a new agent-to-agent exchange should take minimal effort, ideally generated by a model from
a short brief. The kids' gear exchange had been mixed into the platform slices.

## Decision
- Platform code lives in `src/` and knows nothing about any one app.
- An app is `apps/<id>/app.config.ts` plus data, validated by a zod schema (`src/lib/app-config`).
- Safety-critical invariants (always-ask topics, relay, privacy) live in the platform and are enforced by the
  schema; an app cannot relax them.
- Import boundaries are lint-enforced: platform never imports an app; an app imports only `@agora/app-config`.

## Consequences
- A generated app can only break itself, not the platform's guarantees.
- The config schema is the contract a model follows; it must stay small and well documented.
- Slice names such as `family` remain for now; they are the platform's participant profile and use the app's noun.
